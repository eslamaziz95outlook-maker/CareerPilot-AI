# Roadmap

This roadmap describes intended work, not completed functionality.

## 0.1.x — harden the MVP

- Expand deterministic matching regression tests
- Improve empty/error/loading states
- Improve keyboard and screen-reader behavior
- Document score semantics and demo-data boundaries
- Add production deployment guidance for live mode

## 0.2 — evidence model

- Candidate-reviewed document extraction
- Evidence objects with source-document references
- Claim verification and conflict handling
- Better construction-industry taxonomy and synonyms
- Explicit confidence/unknown states

## 0.3 — application workflow

- Evidence-cited CV tailoring
- Evidence-cited cover-letter drafting
- Exportable application packs
- User-editable reusable preferences
- Improved application tracker persistence

## Later

- Arabic/English terminology expansion and localization QA
- Accessibility audit against WCAG guidance
- Pluggable model/provider layer for optional live analysis
- Durable server-side rate limiting and abuse prevention
- Maintainer automation for releases, dependency review, and security scanning
- Privacy-preserving analytics only if the community finds them useful
