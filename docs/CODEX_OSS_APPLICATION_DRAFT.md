## Why this repository qualifies — draft

CareerPilot AI is an open-source Arabic/English career workspace for construction professionals. It focuses on evidence-grounded job matching: verified candidate evidence is separated from partial and missing requirements instead of inventing qualifications. I maintain the product, matching logic, tests, documentation, security guidance, issues, and releases, with a roadmap for document evidence citations and broader construction workflows.

## Planned use of API credits — draft

API credits would support an opt-in live analysis mode for maintainers and contributors: structured job-requirement extraction, evidence-grounded matching experiments, regression/evaluation datasets built from synthetic job descriptions, and testing of citation-aware application drafting. Demo mode remains deterministic and keyless. Credits would not be used to fabricate qualifications or automate job submissions.
