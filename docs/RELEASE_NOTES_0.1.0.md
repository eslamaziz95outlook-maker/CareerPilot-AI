# CareerPilot AI v0.1.0 — draft release notes

> Draft only. Publish these notes when the first public release is actually tagged.

CareerPilot AI v0.1.0 is the first open-source MVP of a bilingual career workspace for construction professionals.

Highlights:

- Arabic/English interface with RTL/LTR support
- local browser Career Vault for common career-document formats
- deterministic, evidence-grounded construction job matching
- transparent match/partial/missing requirement groups and score breakdown
- optional server-side OpenAI integration behind explicit configuration
- contributor, security, CI, test, and roadmap foundations for public maintenance

Known limitations are documented in the README and ROADMAP. The release is intended for evaluation and contribution, not as a production-grade automated hiring system.
